One joke about cats, one line, under 200 characters, nothing else.

## The joke

> My cat knocked my laptop off the desk, sat on the warm keyboard spot, and looked at me like I was the clumsy one.

113 characters, one line.

## How it works

`main.py` writes that exact fixed line to `/output/entry.txt`.
The output is deterministic: the same bytes on every run, with no
randomness, no clock reads, no network and no input files.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
